# One More — demo walkthrough

70-second silent, captioned MP4 made from actual app captures. This is an edited screenshot walkthrough, not a continuous live screen recording. All workout data shown was created for demonstration in an isolated journal.

- **0:05 — Built for the next set.** Choose a workout and start a session. The same journal works on desktop and phone.
- **0:12 — Two sets. Both saved.** Record weight and reps. Identical intentional sets stay separate; request replays cannot duplicate a write.
- **0:20 — Correct it in plain text.** “Change set 2 to 7 reps.” The parser proposes the exact change and waits for confirmation.
- **0:28 — A correction you can trust.** Set 2 now shows 7 reps. Version checks protect against stale edits, and the previous values remain in the audit log.
- **0:36 — Keep the context.** Save setup notes alongside the numbers. Browser drafts survive reloads; saved notes live in SQLite.
- **0:43 — Find the session again.** Search by workout, exercise, or saved notes. This search finds the narrower-grip note and the corrected sets.
- **0:50 — Follow each movement.** Switch between heaviest set, total volume, and reps. Sample workouts are included explicitly for this demo.
- **0:57 — A journal that fits.** The responsive phone layout keeps the same history and measurements. This is a browser viewport demonstration.
